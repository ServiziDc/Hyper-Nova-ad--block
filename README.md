# HyperNova Ad Blocker – sito web

Sito ufficiale dell'estensione HyperNova Ad Blocker per Google Chrome.

## Pubblicarlo con GitHub Pages

1. Crea un nuovo repository pubblico su GitHub, per esempio `hypernova-ad-blocker`.
2. Carica **tutti** i file di questa cartella (Add file → Upload files, trascina tutto e fai Commit).
3. Vai su **Settings → Pages**, alla voce *Source* scegli **Deploy from a branch**, branch **main**, cartella **/ (root)** e salva.
4. Dopo 1–2 minuti il sito è online a `https://TUO-UTENTE.github.io/hypernova-ad-blocker/`.

Link utili dopo la pubblicazione:
- Informativa privacy (da incollare nel Chrome Web Store): `https://TUO-UTENTE.github.io/hypernova-ad-blocker/privacy.html`

Quando l'estensione è approvata sul Chrome Web Store, apri `index.html` e incolla il link nella riga `const STORE_URL = '';`.
